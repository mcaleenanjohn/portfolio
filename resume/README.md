# Resume

`JohnMcAleenan_Resume2026.pdf` is the downloadable résumé.

Clicking **Resume** in the nav (or the About section) opens the résumé
modal — a formatted, scrollable version whose content lives in
`assets/js/main.js` (`resumeModal`). The modal's **Download PDF** button
and the no-JS fallback both point at this PDF. To update: replace the
PDF here (keep the filename) and edit the modal content in `main.js`.
